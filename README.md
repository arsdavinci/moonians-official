# ムーニアンズ公式ホームページ

パステルカラーとサイバーパンクを合わせた静的サイトです。

- 公開：GitHub Pages / mainブランチのルート
- 構成：HTML、CSS、JavaScript。ビルド・外部APIキーは不要です。
- 画像：assets 内。本人提供の素材を使用しています。
- ローカル確認：このディレクトリで `python -m http.server 8765 --bind 127.0.0.1`
- SNSリンク、プロフィール、活動記録：index.html
- 参考資料：sources.html

担当は本人確認済み。らんぴょんがツッコミ、ぴょんぴーがボケです。
日々の投稿はSNSへのリンクで案内し、SNSを自動取得する仕組みは使用していません。
独自ドメインは未設定です。既存のミュージックワールドの設定は変更していません。

## インタラクション

`experience.css` と `experience.js` が街の探索演出を担当します。

- 本人提供の月内部都市を主役にした、3つの風景の切り替え
- 軽量なCanvasの光、マウスに反応する奥行き、スクロール連動の表示
- 昼夜モードと動きを抑える設定（ブラウザー内に保存）
- 二人の挨拶メッセージ（定型文。外部AIとの通信なし）
- サイト内ガイド検索（Ctrl / Command + K）
- 6セクションの訪問スタンプと、SVGの記念パスポート保存

個人情報を集める仕組みはありません。スタンプ・配色・動きの設定のみをlocalStorageに保存します。
動きを抑えるOS設定に対応し、画面外や非表示タブではCanvasのアニメーションを停止します。

## BGMプレーヤー

本人提供の「Theme 全部.wav」を192kbpsのMP3に変換し、`assets/audio/bokura-wa-moonians.mp3` として使用しています。フル尺約3分6秒で、元のWAVは変更していません。

- ページを開いたときに、音楽を流すか確認します。同じページ内の移動では再確認しません。
- 「はい」を押すと再生開始。「いいえ」やEscでは無音のままです。後から再生ボタンで開始できます。
- 再生・一時停止・停止、再生位置、ミュート、音量を操作できます。停止は曲の先頭に戻します。
- 曲はループ再生します。スクロール後も、画面下の「音楽」から操作できます。
- 記憶するのは音量だけです。音楽を許可する選択は、ページを開くたびに確認します。
- 確認前の自動再生や音源の先読みは行いません。


## 日本語・英語

右上の日本語 / ENで、ページ内の文章・操作案内とヘッダー／フッターのロゴを切り替えます。音楽や現在の位置は維持します。英語ロゴは本人提供の `moonians-logo-English.png` をそのまま使用しています。

表示言語はURLの `?lang=ja` / `?lang=en`、保存された選択、ブラウザーで優先する日本語・英語の順で決定します。対応言語がない場合は日本語です。IPアドレスからの国の推定や位置情報取得は行いません。言語の選択は `moonians.language` としてブラウザーに保存されます。

`language.js` の対訳表を使って静的な文章と追加される操作画面を翻訳し、地名や番組名の固有名詞は英語表記またはローマ字で案内します。画像自体に含まれる文字と日本語の楽曲は元のままです。参考資料ページも両言語に対応しています。


## ムーニアンズTV

「街からのおたより」に、本人提供のTVロゴとパステルの案内画像を配置しています。ポスターは今回提供された画像を `assets/moonians-tv-poster.png` としてそのまま使用しています。チャンネルは `https://youtube.com/@moonians` へ接続しています。

長尺動画の再生リスト `UULFBpwXFh6RjG9uLDooOS7pDw` を、2026年11月10日にYouTube上で確認しました。動画欄の「新しい順」と同じく、先頭は「あなたは何問正解できる？実在する面白いことわざクイズ！」です。埋め込みはこのリストの先頭を使うため、動画IDを固定せず、YouTube側のリストに更新が反映されます。

- 通常はポスターを表示。マウスで画面に重ねている間は、最新の長尺動画を無音でプレビューします。
- カーソルを外す、画面外へスクロールする、別タブへ移ると、無音プレビューを停止してポスターに戻します。
- 再生ボタンのクリック／タップで音声付きの通常再生へ移り、BGMを一時停止します。音声付き再生では、ホバーを外しても止まりません。
- YouTube IFrame Player APIは最初のホバー／再生操作で読み込みます。APIを読み込めない場合も音声付きの埋め込みとYouTubeへのリンクを使えます。
- スマホはタップで再生し、プレーヤーは高さ200px以上を確保します。

表示と再生は `tv.css` と `tv.js` が担当します。YouTube側でリストを利用できなくなった場合は、表示されるチャンネル・再生リストへのリンクから視聴できます。

### コンパクト表示

BGMカードは通常、曲名と配信リンクだけを表示します。マウスを重ねると操作部を開き、離すと閉じます。スマホは曲名のタップ、キーボードはEnter/Spaceで開閉し、Escでも閉じられます。キーボードで操作中は、カーソルが外れても操作部を維持します。

閉じた状態は曲名と配信リンクだけの小さなカードです。開くと曲名・再生状態、横並びの再生／停止ボタン、経過時間／全長、操作できる横型タイムラインを表示し、右端に短い縦型音量バーを配置します。挨拶は表示せず、配信リンクは常時残しています。画面下の「音楽」も同じ操作部を開きます。タイムラインと音量は両方のプレーヤーで同期します。

## 音の動作確認

本人の希望により、作業中の突然の大音量を避けます。ブラウザーで確認するときは `?quiet-test=1` を付けた確認画面を使用してください。この画面ではBGM・YouTubeの音量を5%に設定します。YouTubeは初期状態をミュートとし、音声付き再生への移行前に音量を設定します。普通の閲覧URLの初期音量には影響しません。ホバー確認は無音で行い、音声付きテストは必要なときだけ小音量で行います。


## MOON OS スキン（パステルネオン × 宇宙）

2026年11月11日に、見た目と演出を `cyber.css` / `cyber.js` で作り直しました。従来の `style.css`・`experience.css`・`music.css`・`language.css`・`tv.css` は `@layer legacy` として読み込み、`cyber.css` が上から塗り替えます。色は `cyber.css` 冒頭のトークン（`--c-bg` など）で昼・夜まとめて変更できます。

- 既定は夜（宇宙）テーマ。ドックの「昼の街へ」でパステルの昼テーマに切り替え、選択はブラウザーに保存されます。既定を昼に戻す場合は `experience.js` の `store.get('night', true)` を `false` にし、各HTML先頭のインラインスクリプトの判定も合わせます。
- 起動演出「MOON GATE」は1回の訪問（タブ）につき1度だけ表示。クリック・キー入力でスキップでき、動きを抑える設定では表示しません。音楽の確認は起動演出の後に開きます。
- 全ページ共通の星空Canvas（流れ星・スクロール視差）、カーソルリング、クリックの星、HUD枠と東京時刻、その日の月齢（計算値）、右端の軌道レール、活動記録のタイムライン、スクロール速度で加速するマーキー。
- 風景切り替えに「04 宇宙船コックピット」（`assets/scene-cockpit.jpg`）を追加。切り替え時はグリッチ演出。
- テーマ切り替えは View Transitions による円形のワイプ（非対応ブラウザーは即時切り替え）。
- 隠し要素：キーボードで `moon` と入力、またはフッターの大きな MOONIANS を3回タップすると「低重力モード」。
- 追加フォント：M PLUS Rounded 1c、Unbounded（Google Fonts）。
